# knowledge/ — the project wiki

_Durable reference about how your project's capabilities work. Grep on demand; never preload the whole
thing. One file per capability or hard-won lesson. This is where a correction becomes a rule instead
of a repeated conversation._

## What lives here

- **How a capability works** — `knowledge/<capability>.md`: the design, the seams, the traps. Written
  when you learn something an agent would otherwise rediscover the hard way.
- **Lessons / scars** — a bug that cost real time, and the rule that prevents it next time. Link it
  from the code or the doc it protects.

## What does NOT live here

- Open work → the tracker.
- Current live state → `state/STATE.md`.
- Settled decisions → `state/decisions.md`.
- How we operate → `operating/`.
